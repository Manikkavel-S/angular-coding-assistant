## 🎯 Step-by-Step Instructions to Capture Screenshots
1. Run the local dev server:
   ```bash
   npm start
   ```
2. Open Google Chrome or Microsoft Edge at `http://localhost:4200`.
3. Press `F11` (or maximize the browser window) for a clean, professional view.
4. Navigate sequentially through each route listed above.
5. Use Windows Snipping Tool (`Win + Shift + S`) or the browser full-page screenshot tool (`Ctrl + Shift + P` → "Capture full size screenshot") to capture each view.
6. Save the captured images into `docs/screenshots/` matching the filenames above.
